# Project Workflow

Before writing or changing code, read the project documentation.

Required context files:

- AGENTS.md
- docs/START_HERE.md
- docs/CONTEXT.md
- docs/TASKS.md
- docs/DECISIONS.md

For non-trivial work:

1. Restate the goal.
2. Identify known constraints.
3. Identify unknowns.
4. Ask focused questions if needed.
5. Propose a plan before coding.
6. Implement one small task at a time.
7. Test the work.
8. Update the docs.

Use AI Hero skills when helpful:

- Use `grill-me` when requirements are unclear.
- Use `to-prd` when a feature needs requirements.
- Use `to-issues` when a plan needs tasks.
- Use `tdd` when behavior should be test-driven.
- Use `diagnose` when debugging.
- Use `handoff` when ending a long session.

Do not perform destructive terminal or git actions without explicit approval.
