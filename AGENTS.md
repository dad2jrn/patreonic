# Agent Instructions

This project uses Ron's AI-assisted development workflow.

Before doing non-trivial work:

1. Read this file.
2. Read `.clinerules/`.
3. Read `docs/CONTEXT.md`.
4. Read `docs/TASKS.md`.
5. Read `docs/DECISIONS.md`.

Default workflow:

1. Understand the project.
2. Clarify ambiguity.
3. Create or update the plan.
4. Implement one small vertical slice.
5. Test the work.
6. Update documentation.
7. Summarize what changed.

Do not make broad, unrelated changes.

Do not rush into code.

Preserve important project context in the docs folder.
